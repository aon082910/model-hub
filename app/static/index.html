Duplicates

Files that are exactly the same. Pick the one to keep in each group: it receives the tags, collections, projects, notes, print history and listing link of the others. Combine info only shares that information and leaves every file where it is. Keep this, delete the others also deletes the other files from your library folder (each file is checked again first, and only a true copy of the one you keep can be deleted).

Same shape, different file

These files have the same geometry but are not identical (a re-export, a different slicer, a repaired copy...). They are only listed here.

          Model Sites

          Printables, MakerWorld and Sketchfab need no account. The others need a key or token that you create on their site and paste here; it is kept on this server and never shown again. Use Test to check a key right away.

          Library Cleanup

          Model Hub only lists model files (.stl .3mf .obj .step .stp .fbx). Entries for other file types (zips, notes, drawings) that were indexed before this limit can be removed from the index. The files themselves are never touched.

          Browser Extension

          Sends model files from Printables, MakerWorld, Thingiverse, MyMiniFactory, Cults3D and Sketchfab pages to this library, using your own logged-in browser, which is how you add files from sites that do not allow downloads elsewhere.

          Download the extension (.zip)

          Chrome / Edge: unzip it, open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the folder. Firefox: open about:debugging, This Firefox, Load Temporary Add-on and pick manifest.json. Then click the extension's icon and enter this server's address and the key below.

          Backup

          A backup holds everything Model Hub knows apart from the model files themselves: tags, collections, projects, supplies, filament, links to listings, notes, the wishlist, the print log and the saved pictures. Thumbnails can be rebuilt (see above), and passwords, the extension key and every site key are left out, so restoring never replaces your current logins.

          Library information

          Export what Model Hub knows about your models (tags, collections, projects, designer, license, notes, the listing each came from, print counts; not the files), or import it back or a spreadsheet from another tool. Rows are matched to your models by content hash, then path, then a file name that is unique.

          Print planning

          How many hours a day each printer may run. The calendar warns about days that need more than your printers have, and plans waiting prints into days with room.

          Share the whole library

          A secret link that lets anyone who has it browse every model, read-only and without an account: names, pictures, tags, designer and what worked. Never notes, print history or costs. Share a single collection from the Collections tab instead if that is enough.

          Home Assistant and MQTT

          Publish printer state and library numbers to an MQTT broker, with Home Assistant auto-discovery. Leave the address empty to keep it off. Model Hub only publishes; nothing can be controlled this way.

          Updates

          API tokens

          Keys for scripts and other programs (Home Assistant, a slicer plugin, your own tools). Send one as Authorization: Bearer mh_.... read can look at everything a viewer can, write can do what a member can (never settings, backups, users or tokens), import can only add models. A key is shown once, when you make it; only a fingerprint is kept.

          People

          Other logins for this Model Hub. A member can use everything in the library, projects, supplies, wishlist and so on, but not Settings, backups, user management or deleting duplicate files. A viewer can only look. Your own login is the administrator.
